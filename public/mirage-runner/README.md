# Mirage Runner

Bundled original `desert-night` scene from [bas3line/ascii](https://github.com/bas3line/ascii), MIT licensed (see vendor/LICENSE). TypeScript annotations removed using Node stripTypeScriptTypes; scene art and palette preserved. Game and compositing are original.

← → / A D steer · P pause · six steady beacons to reach the caravan. Keyboard and touch supported. Start, pause/resume, retry and finite win/loss. Hidden pages and game switcher pause the simulation. Reduced motion freezes decorative scenery. Local best scores tolerate unavailable storage.
