# English bond in a one-colour shader

English bond lays a course of headers, then a course of stretchers. No shading paper fits that change here. The facade returns one colour and already offsets each course by half a unit. An odd course gains a joint at the middle of that unit, and each half takes its own tint, so the course reads as short bricks. The existing per-unit hash stays. Mortar still replaces the joint afterwards, and glass, doors, and the lamp apron are drawn later.

Unreal is not installed here. The picture is the same straight elevation as the crust round, with the bond added. It is not an engine capture.
