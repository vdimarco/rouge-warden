# Research for the shore-grand-arena change

Read-only studies of Shore of the Ancients made before the implementation (2026-10-05). They cite `file:line` at the commit they
studied (around `1d881a1`); lines move as the code changes. Paths under `/tmp/claude-0/...` name scratch scripts from that study;
they are not in the repository.

- `combat-audit.md`: the game scored against the ten combat-fun rules (`docs/combat-fun-system.md`), with proposed mechanics.
- `combat-code-map.md`: where combat lives in the code, with evidence per rule.
- `bots.md`: how the bots decide, why they are easy to beat, and measured fixes.
- `structures-and-pacing.md`: towers, objectives, economy and measured match pacing.
- `map.md`: map geometry and what a bigger map changes.
- `tests.md`: which tests encode geometry, towers and pacing.
- `art.md`: what made the old look read as childish.
- `plan.md`: the combined implementation map.
