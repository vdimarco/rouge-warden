# Through the Gust

## Decision

The third flush uses the existing clog-beat queue. The column is the job marker the street placer already finds. A pass is distance, airborne, and horizontal speed, with an arm so one stay inside the column counts once. The lift is applied when the job emits `gust`, after physics for that frame, using the existing comic word and the existing rope-release sound.

## Rendering

No new rendering technique. The column is the existing goal beam. The pass word is the existing comic word. No outside art source applies.

## Out of scope

The first flush stays the clog card. The King cycle is unchanged. The gust is not added to the odd-job offer list. No sky-anchor swing is reintroduced.
