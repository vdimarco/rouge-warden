## ADDED Requirements

### Requirement: Focused Unreal agent guidance
The development setup SHALL install a bounded reviewed set of UE 5.8 agent skills with the upstream revision and license retained.

#### Scenario: Use installed guidance
- **WHEN** a subsequent Codex turn works on NORD rendering, animation, networking or testing
- **THEN** the corresponding installed skills and their referenced resources are available
- **AND** existing skills are preserved.

### Requirement: Isolated profiling trial
The VibeUE trial SHALL use a pinned checkout and isolated host with recorded build/runtime outcomes before any main-project enablement.

#### Scenario: Validate the plugin
- **WHEN** the trial builds and exercises the plugin on Linux UE 5.8.3
- **THEN** the evidence identifies the source revision, invocation, exit status and available capabilities
- **AND** failures and differences between editor and packaged measurements remain explicit.

### Requirement: Offline instrumental auditions
The music trial SHALL generate neighborhood, race and garage candidates from original instrumental briefs with prompts, seeds, model revision and source license recorded.

#### Scenario: Review music candidates
- **WHEN** a candidate finishes generation
- **THEN** it is available as an ordinary local audio file with duration, sample rate, channel count and signal checks
- **AND** production audio is unchanged until a candidate is selected and integrated.

### Requirement: Preserve active play and concurrent work
Tool adoption SHALL preserve the main project configuration, map, installed package and campaign saves, while respecting live service and GPU ownership.

#### Scenario: Finish the trial
- **WHEN** tool work ends
- **THEN** protected identities match their trial baseline
- **AND** any deliberately paused owned service is restored and verified
- **AND** unrelated jobs, tunnels and concurrent gameplay/audio edits remain preserved.
