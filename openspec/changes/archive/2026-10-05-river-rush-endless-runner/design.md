## Direction and decisions
Preserve the cinematic forest/gold menu and Higgsfield loop; gameplay becomes vivid turquoise, forward perspective and compact geometric sans HUD. Generate a gameplay concept and production sprites/environment before implementing the presentation. Keep the approved front-facing adult character in only a modest loincloth with long hair so likeness remains visible.

The core loop is read the next obstacle, choose a lane or action, collect coins, build a streak, activate Rush, survive faster combinations, and retry. No sustained unlock input or waiting for a single collectible. Lane input is discrete and immediately authoritative with a short visual interpolation. Jump lasts .86 seconds and duck .82 seconds; inputs can cancel the opposite action. Keyboard uses A/D or left/right, W/up/Space jump, S/down duck, Shift Rush. Touch supports four-direction swipes and explicit buttons.

Distance-based seeded rows use a minimum reaction interval that scales with maximum speed, never block all three lanes with unjumpable rocks, and have a clear lane or an all-lane jump/duck barrier. Dense action routes earn extra points, a legal avoidance or action route remains available. Coin trails guide the route; jumps and ducks add charge. A full charge grants four seconds of fast invulnerability and cannot recharge itself. Rotating trick/coin/distance challenges pay 500 points once and set fresh relative targets. Magnet lasts eight seconds, shield absorbs one impact, and the first run starts protected. Missed coins expire the streak; shield hits break it; fatal collisions explain the correct move.

Keep simulation separate from presentation, bounded entities/effects, simulation-time animation, paused frame equality, live reduced-motion response, silent video fallback and stored score validation. Legacy treasure scores use a version field so runner best scores start comparable while cabinet storage retains its existing key. Unsupported WebMCP stays guarded.

A simulated delayed-input player checks many seeds through increasing difficulty. Playwright fallback (no callable interactive browser tools) exercises actual keyboard/touch, pause/retry, video fallback, shared switcher, local score and mobile/desktop/landscape layout. Compare the generated concept with native browser captures for layout, copy, palette, art and responsiveness. Measure render/frame budgets in this browser, without claiming physical-phone performance. Build and publish the exact verified output to the existing Warden production route.
