## Why
The current treasure race has long gaps between decisions, opaque key timing, and little reason to replay. The user asks for a genuinely fun runner with the pace of Subway Surfers.

## What Changes
- Replace the two-minute treasure race and balance-based Surge with an endless three-lane raft runner.
- Add immediate lane changes, jumps, ducks, legible obstacle chains, coin streaks, magnet/shield power-ups and a charge-driven invulnerable Rush.
- Increase speed gradually, keep every obstacle row escapable, teach actions in the opening run, and offer immediate retries with best-score persistence.
- Render a forward perspective river using generated environment and character assets. Preserve the approved face, long hair, modest loincloth, Higgsfield living menu, arcade route, switcher and audio lifecycle.

## Impact
Game engine, renderer, input, HUD, menus, tests, committed static build, cabinet text and current River Rush requirements. No changes to other games.
