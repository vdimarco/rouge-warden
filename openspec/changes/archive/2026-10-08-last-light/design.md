# Last Light design

## Direction and source of truth
User references: https://ascii.rest/ocean-sunset/, the complete https://ascii.rest/#pieces catalogue, and https://github.com/bas3line/ascii.
A short sailing game uses original ocean-sunset, night-coast and aurora-fjord scene modules. The full catalogue includes scenes, UI, data, type, logos, companies, distros, shapes, space, physics, nature, creatures, objects, generative and effects.

Generated concept: a wide coloured halftone sea above a centred monospace title and set-sail action. The source scenes are authoritative for art and colours; the generated landscape is intentionally interpreted through those live procedural assets. ASCII glyph sprites are an intentional deviation from raster production assets to meet the user's requested style.

## Tokens and inventory
- Ground: dark violet #0b0817. Text: ivory #fff5d8. Muted: #9c90b8. Accent: gold #ffcd62. Hazards: rose #ff5d8f.
- Layout: 1440px maximum, 24px desktop / 12px phone gutters, 2:1 scene, open console, thin header divider, no card grid.
- Type: system monospace throughout; 19px brand, 14px utility, 28–44px title, 20px primary action, 11–13px help.
- Scene: original 200×100 coloured halftone glyphs, no image overlays.
- Gameplay art: ivory ASCII sloop, gold spark, rose rock, brief code-native text feedback.
- Copy: Last Light; [ arcade ]; sunset crossing; lights 0; hull 3/3; Carry the last sparks home.; [ set sail ]; arrows / WASD to steer · space to dash · P to pause.
- Additional necessary gameplay copy: crossing/time/score, best, dash cooldown, pause/resume/retry, victory/wreck feedback, touch controls, attribution and shared switcher.
- Architecture: DOM-free engine; browser controller; locally vendored scenes; atlas renderer; responsive HTML/CSS; existing arcade cabinet/switcher.
- Motion: decorative animation stops under reduced motion, all simulation freezes on pause/hidden/completion. Essential steering remains active.
- Responsive: desktop 1440×900, phone 390×844, landscape 844×390; touch controls and scrollable console. No page-wide fixed body.

## Validation
- Eight Node simulation tests pass: bounds and diagonal steering, pause freeze, dash/cooldown, sparks/streaks, damage/invulnerability, wreck, finite victory, storage and three complete seeded voyages.
- Original and vendored scene frames and palette arrays match at t=0, 1 and 20 seconds for all three scenes.
- OpenSpec 1.14.1 strict change validation passes.
- Playwright with system Chromium verifies identity, meaningful canvas/content, no runtime errors, keyboard start/dash/steer/pause/resume/retry, play-area focus, multi-pointer touch release/cancel, reduced-motion stillness, and horizontal overflow at 1440×900, 390×844 and 844×390.
- Additional browser QA verifies the arcade cabinet path (Action picker → Last Light → 5 → 1 → game), switch-menu pausing and both downstream scene renderers.
- Generated concept was inspected with view_image at /tmp/last-light-concept.png. Latest screenshots were inspected at /tmp/last-light-qa/desktop-title.png, desktop-play.png, 390x844.png, 844x390.png and native-title.png. Native concept dimensions 1586×992 were checked in Chromium.
- Browser plugin is absent; regular Playwright is the fallback. Downloaded Playwright Chromium was unavailable under network policy, so the existing /usr/bin/chromium was used.
- Full collection: 216 source pieces rendered in four contact sheets and inspected with view_image, covering all 15 categories.
- Physical phones, other browser engines and hardware performance have not been tested. No audio is generated by this game.

No remaining material visual or interaction mismatch was found in the checked viewports.
