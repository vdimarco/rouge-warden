# Last Light

## Why
Add a playable ASCII sailing game inspired by the full ascii.rest collection, particularly ocean sunset, night coast, aurora fjord, creatures, physics and terminal controls.

## What Changes
- Add `/last-light/` as a static, self-contained three-crossing game.
- Use locally bundled MIT-licensed ascii.rest scenes and custom ASCII gameplay glyphs.
- Support keyboard and touch steering, dash, pause, restart, finite victory/loss and guarded best-score persistence.
- Add Cottage Arcade cabinet and shared switcher entry.

## Impact
New `last-light` capability, static game files, focused simulation/browser QA, arcade launcher integration. No backend required.
