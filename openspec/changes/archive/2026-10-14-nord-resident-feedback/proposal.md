# Resident and activity feedback

Adapt the inspected Grand Theft Argon interaction and feedback ideas to the current NORD game. The integrated game already has traffic, engine/tire audio, a driving camera and a replayable street race. Add original Québec French ambient greetings, resident acknowledgement and approaching-car warnings, semantic progress/completion sound cues, and a shared session race result/best clean lap.

Preserve the existing campaign, save format, E/T controls, private dialogue priority, authored routes, map/assets, browser layouts and character-centered camera. Use original sounds; copy no Argon code or media. Work targets `games/nord-unreal`; the older standalone prototype was subsequently archived and its launchers disabled at the user's request.
