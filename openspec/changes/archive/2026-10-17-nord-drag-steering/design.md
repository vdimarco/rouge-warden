# Design

Reuse the existing pointer capture and native A/D key protocol. A wheel-sized horizontal control has a center deadzone, direction feedback, and release-to-center. Keep two accessible buttons within the wheel for keyboard activation. Gas and Brake stay in the existing adjacent grid. Scope: browser markup, styles, pointer handler, input tests and player hint; no native vehicle physics changes. Check 320/390 portrait and landscape layout and interruption release.
