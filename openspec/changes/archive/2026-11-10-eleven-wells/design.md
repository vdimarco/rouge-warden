The prototypes are vanilla canvas games sharing one small engine (`engine.js`), with a theme stylesheet per game under `games/`. The page loads `/arcade/quiet.js` first so its Web Audio stops when the page is hidden. Fonts load from Google Fonts. It stands in the Lab group because it is a set of experiments, and it is `labOnly` in the switcher.

Two fixes came out of checking it in the arcade. The shared stylesheet gives `.modal-layer` and `.board-overlay` a grid display, which beat the `hidden` attribute once the page was outside the artifact host, so an empty dark layer covered every game; `[hidden]` now wins. Sound is not scheduled or resumed while the page is hidden (the engine's `K.audio()` and Niteshift's own music scheduler), so `quiet.js` keeps it suspended. `qa/arcade/quiet.mjs` plays the page through Niteshift, the prototype with a backing track.
