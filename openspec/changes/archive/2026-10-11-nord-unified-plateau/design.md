# Design

Source: GTA-NORD main `eddc54c`; destination Warden `codex/nord-unreal` at `e7901824`. These independent repositories contain different versions of shared gameplay. Import the baked Plateau map and the environment assets/data/native pedestrian and vegetation classes it references, while retaining Warden's newer gameplay, campaign, map coordinate frame, traffic graph, crew and period vehicles. Leave the GTA-NORD checkout read only.

Back up the destination map, differing shared dependencies and actual SaveGames before mutations. Use the exact saved Plateau map as the environment base, then transplant Warden's **14 authored `QuebecParkResident` routes and eight driveable parked `QuebecCar` actors** from a temporary old-map sublevel. Remove the staging sublevel before saving; the result has 2,701 actors (2,679 baked environment plus 22 restored gameplay). Do not transplant Warden's previous municipal building, park-instance or comic-tree layers over the Plateau geometry. `upgrade_plateau.py` is guarded to refresh only this already integrated baked map; it was not used for the merge and has not yet passed an end-to-end regeneration run.

Keep the native Warden road graph, generated header, mission coordinates and save format. Preserve the Plateau `BaseGeometry` OBJ inputs separately, so map regeneration does not overwrite Warden's `Data/LaFontaine` layout. Inspect a fresh saved map for actor inventory, collision, pedestrian/traffic routes and gameplay, then run story/save/driving/population and rendered checks. The mapped Plateau tree meshes use `NoCollision`; this limitation and estimated façades/heights must remain explicit. Retain source/license notices and do not claim Google Street View parity.

Build/cook once and synchronize the local package from the browser package without deleting Saved* directories. Verify package identity. GPU jobs are serialized with the separate trailer chat held CPU-only; browser startup uses its existing 12 GB preflight. Private ICE credentials and local recovery files remain ignored. Physical phone/off-LAN and subjective art/driving acceptance are separate from automated QA.

The native HUD uses compact charcoal, cream and gold panels with the Montréal identity, mission information, radar, contextual controls and speed. Keep existing feedback and private view settings; inspect actual 720p/1080p mission and driving renders.

Reconcile the Arcade with production main before publishing, preserving every existing game and API. Add only the GTA collection/cabinet, switcher entry and responsive title page. Publish the complete static/API tree to the existing Warden Vercel project; keep trailer binaries ignored and record their hashes. The accepted 38-second Cinematic3 trailer follows the game release checks and uses current cast, car and native rescue/race footage. Test real poster/video decoding, byte ranges, modal dismissal/focus and navigation in a protected preview before production.
