# Import NORD Unreal project

## Why
The Montréal Unreal project currently lives outside Warden. Preserve the working map, gameplay, assets, and reproducible build instructions in this repository.

## What changes
Add the standalone project under `games/nord-unreal/`, retain geographic/art provenance and verification reports, exclude generated builds/caches/geometry and local credentials, and link its documentation from the repository README.

## Scope
This imports the current Unreal project. Browser arcade integration, Google streaming, Street View parity, private interiors, and new gameplay are not part of this repository import.
