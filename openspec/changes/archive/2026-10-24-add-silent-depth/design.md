# Decisions

- Ship the existing static ES modules in `public/silent-depth/`, the compressed ocean in its assets folder, tests in `qa/silent-depth/`. No bundler, dependency, API or game asset service is required. Keep the standalone source intact until the hosted version is verified.
- Reuse the arcade's cabinet markup, Strategy collection, `GAMES` registry, game switcher and `/arcade/quiet.js`. The route, id and title agree everywhere. Cabinet art is a 480px WebP under 60KB derived from the real periscope screenshot. Add the sound-start sequence to quiet.mjs.
- Wave research: [NVIDIA GPU Gems, Effective Water Simulation](https://developer.nvidia.com/gpugems/gpugems/part-i-natural-effects/chapter-1-effective-water-simulation-physical-models) describes independent traveling sine waves and their analytical slopes. Adapt that height/slope approach to texture displacement and reflection modulation in one small WebGL pass. [MDN, Using textures in WebGL](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/Tutorial/Using_textures_in_WebGL) informs texture setup and non-power-of-two clamp/linear sampling. Existing river and swing graphics use different rendering systems; importing their engines for a periscope backdrop would be disproportionate.
- Preserve the generated ocean's palette and stable horizon. Apply displacement only below the horizon, diminish it with distance, and let differently directed swells and small ripples evolve independently. The sky, UI and ships are not displaced. No moving ruler strokes as substitute waves. Cap the background buffer to CSS resolution/1440px width while retaining the high-DPI instrument canvas. Visual time is independent of simulation acceleration, freezes when paused, and is fixed for reduced motion. If WebGL is unavailable/lost, the existing static ocean remains playable; restoration rebuilds the pass.
- Scope reaches game renderer/time loop, page shell, arcade cabinet/group/registry, audio verification and deployment. It does not alter other games, shared audio implementation, ranking behavior, domains or firewall rules. Public access uses the existing Vercel project `warden`, custom domain `arcade.uptick.systems`, through the repository's normal PR/main deployment path.
- Checks: Node engine tests; actual full patrol and switcher route on desktop/touch; time-separated pixel checks for moving water, unchanged sky, pause, reduced motion and graphics fallback; cabinet/All Games navigation and 320/390/1280 screenshots; quiet.mjs for this game's context. Physical phone confirmation remains user-dependent.

## Commander hub clarification

The control room is the default station. A generated, empty vintage research-vessel cabin supplies the environment; chart table, observation column, listening position, instrument console and helm get code-native accessible hotspot buttons. Persistent station tabs offer the same navigation, with horizontal scrolling on phones. A separate torpedo-control pane exposes all four tube selections, readiness, lead bearing and intercept time; it routes firing through the existing shared engine. The scope has an explicit raise/lower order; a lowered scope cannot build a visual solution, and avoids the raised-scope visibility penalty. The central helm continues to command the same course/speed/depth from every station. No character locomotion or new movement physics are introduced.
