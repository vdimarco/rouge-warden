# Add the Inkbound Godot project

## Why

Inkbound is a playable desktop prototype developed outside Warden. Bring the current version into the repository so a local checkout can launch the game and reproduce the artwork.

## What changes

Import the project under `games/inkbound/` with its three rooms, the rigged Ashwarden, and the assets Godot reads at runtime. Document launch and regeneration from that directory.

## Scope

This import covers the native desktop project. The browser arcade has its own release workflow.
