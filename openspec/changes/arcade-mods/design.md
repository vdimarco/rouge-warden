# Design

**One folder per mod, one marketplace.** Each mod is a plugin folder under `mods/`: `.claude-plugin/plugin.json`, `hooks/hooks.json`, the hooks module `hooks/register.tsx`, its own helper files, a state contract in `types/index.d.ts` when it keeps drawn values in `$.state`, and its tests in `tests/`. `mods/.claude-plugin/marketplace.json` lists all ten with relative sources, so `claude plugin marketplace add ./mods` installs from the folder itself and `/reload-plugins` picks up edits. `claude --plugin-dir mods/<name>` loads one mod for one session.

**Copies, not links.** A plugin imports only its own files. The game code and data that a mod reuses are copied into it: the Full Tilt physics and table, the Primordia Lenia core and species, the Reel It In species, and the Shore of the Ancients announcer clips with their credits. Helpers that several mods share live once in `mods/shared/` and are copied into each mod's `hooks/shared/`. `mods/sync.mjs` makes every copy, and `--check` fails on a stale or missing one. The game pages stay the source of truth.

**Judging a check run.** `shared/checks.ts` decides what a Bash command is: a check run (tests, QA and simulation scripts, type checks, lint, plugin tests), a build, or neither. A run is green when the tool reports no error, it was not stopped or sent to the background, and its output has no failure line (`FAIL`, `✗`, `not ok`, `N failed` with N above 0). The output check catches a failure that a pipe to `tail` hides. The announcer, the cabinet spinner and the creel all use it, so they agree.

**Merges.** A merged pull request shows in three ways: a Bash result whose `gitOperation.pr.action` is `merged`, a green call of the GitHub connector's `merge_pull_request`, and a GitHub event delivered to a watched session. `shared/checks.ts` reads all three.

**Terminal first, every surface works.** The terminal draws the animated panes as one `Raster` of half-block cells (two pixels a cell), repainted with `$.ui.blit` from a `$.clock.every` timer, with no render pass. The desktop, VS Code and mobile surfaces have no `Raster`, so the same pane draws an `Svg` frame there from a `$.state` value that the timer writes at most 8 times a second, and only while such a surface drew the pane in the last few seconds. Bands and lists are plain `Box` and `Text` and draw the same everywhere.

**State and memory.** Values that a drawing reads are `$.state` atoms, declared in each mod's contract, so a write redraws exactly the readers and survives a hot reload. Values that last between sessions (the best streak, tokens, the creel, the best pinball score) go to `$.store`. Module variables hold only what can start over on a reload, such as a frame counter.

**Sound.** The announcer plays its MP3 clips with `$.audio.play({ asset })`. Claude Code plays a clip with `afplay` on macOS and plays nothing on Linux and Windows. Every call is wrapped, so a missing player is silent. The toast carries the call on every surface. A setting turns the sound off, and another plays "Prepare yourself" when a session starts (off by default).

**Guards that never trap.** The tilt sensor and the wanted level deny only the calls they name: a `git commit` with a broken house rule, or a risky call at five stars. The deny text tells the model the fix. Prompts are never blocked. The person always has a way out: Reset in `/tilt-sensor`, and `/lay-low`. The tilt sensor keeps a rule open from the edit that broke it until the named build runs green. At commit time it also reads `git status`, so a page or a picture that a script changed is checked too. A commit that only stages the files in the same command (`git add -A && git commit`) is covered, because the check reads the working tree, not the index.

**Panes that open unasked.** Attract mode and the photo booth open their panes without a command. Claude Code places such a pane only on a fullscreen terminal 144 columns or wider, or on an app surface that places panes, so they never take over a narrow screen. Attract mode closes its own pane at the next prompt. Every pane stops its timers when it closes.

**Full Tilt input.** A Button hotkey is one press with no release, so a flip key raises the flipper for 140 ms. The cradle needs a held flipper and is not possible from the keys. The table is the classic table of `table.js` (three bumpers, two slingshots, three drop targets, three top lanes), which `qa/lab/tilt.sim.mjs` already checks. The scoring is the mod's own, since the game's scoring belongs to the open-space voyage.

**Lenia size.** The dish is 64 by 64 cells, the size of the drawn field, so no frame is scaled. Its creatures use the Orbium rule at R 13, as in Primordia. Agar on: a glider keeps moving onto fresh agar and leaves a violet trail that grows back.

**Tests.** `claude plugin test` runs each mod's `tests/*.test.ts` against the engine. A test answers every engine call the mod makes (`ui.toast`, `fs.read`, `process.run` and the rest) with its own hooks, so a test reads exactly what the mod did. Drawing tests mount the pane or band on the terminal and the desktop, and on mobile where the mod draws there. `mods/check.mjs` runs `claude plugin validate`, the tests and `tsc` for every mod. `tsc` needs the engine's declarations: it uses `CLAUDE_CODE_TYPES` when set, else the copy that Claude Code lays in a loaded mod's `.claude-plugin/types/`, else it says it skipped.

**Frame budget.** `mods/qa/frames.mjs` imports the frame builders (plain TypeScript that Node 22 runs), times 300 frames of each animated pane, and draws one frame of each to a PNG with Playwright, for a person to look at.
