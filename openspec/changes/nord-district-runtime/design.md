# Design

Reuse `nord-college-bathurst` survey/layout/header/OBJ pipeline and the existing native gameplay, sky, driving, HUD and QA patterns. Toronto remains `/Game/Maps/CollegeBathurst` with its own origin; Montréal remains `/Game/Maps/LaFontaine`. Preserve accepted Montréal data/header/crew packages, campaign slots and original generated art sources. Back up the Montréal map before any explicitly bounded additive extension; preserve its existing gameplay actors and authored environment. Never regenerate the old map to create the new one.

Before new-level creation, preflight every required geometry group, material and class, and require fresh NullRHI authoring. Retain separate saved-map verification and Vulkan captures. Use deterministic modular architectural detail and existing accepted materials for Sneaky Dee’s frontage; record official venue/open-data sources and distinguish surveyed dimensions from artistic estimates. No new dependency is needed.

For the first playable Toronto slice, select district spawn, car recovery, radar geometry/credits and HUD identity by the loaded map. Preserve Montréal’s exact defaults and campaign. Toronto is explicitly free roam until authored Toronto missions exist: no Montréal objectives/progression or save loading/writing there. Keep shared authoritative driving, selection, interaction, private F2 and sky behavior. Expand population/travel in a later checked increment rather than borrowing Montréal coordinates.

Reach: map authoring/preflight tests, native district selection and affected gameplay/HUD/save callers, focused native tests, map cook inventory, explicit local launcher, separate native capture/check fixtures, source/licence records and verification reports. Browser/service integration must respect the active mobile-controls task; preserve its checkout, publication and player slots. Root serializes engine/GPU/service jobs and restores original editor preferences, live package/saves/tunnels after bounded windows. Use managed jobs and existing resource guards, without reducing Epic quality.

Six-hour deadline is 20:09 UTC / 16:09 Montréal. Reuse this checkout’s continuation branch and durable verification log across heartbeat runs. Do not start work that cannot complete or safely stop/restore by the deadline. Paid generation remains capped at the existing US$25 authorization (US$4 reserved for two completed jobs, US$21 uncommitted); current work prefers local geometry/material/rig reuse.

Montréal's bounded expansion opens the already surveyed 200 m eastern context strip: x=55,373.303–75,373.303 cm, y=−46,754.4–69,018.4 cm. Reuse existing context buildings/roads and OSM sources, add a collision floor plus north/south strip boundaries, and move only the existing eastern hidden wall. Hide the old nonblocking fictional closure decorations and author new closures at actual new road exits. Retain all old actors, packages other than the explicitly changed map, mission/park/resident/spawn transforms, original data/header and existing traffic behavior. Additional radar road segments come from a separate extension header. This adds traversable area without claiming detailed façades, sidewalk elevation or municipal fidelity in the background layer. Native checks must prove crossing the former boundary, outer containment, stable campaign routes and current collision/rendering.
