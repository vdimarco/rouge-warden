# Crown shade

Published alpha-card foliage pipelines do not fit this generator. The crowns are already an opaque marching-tetrahedra field in `prepare_environment_refresh.py`. The change stays there: a slightly tighter lobe, a shallow sky well, and two extra leaf materials the existing importer already understands (`Leaf0` dark, `Leaf2` cap). No Rockstar assets.

The offline shade uses the same three canopy files before and after, from one camera, so the comparison is the mesh rather than a relit scene.
