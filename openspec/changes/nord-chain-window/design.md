# Longer ink, longer beam

No new rendering technique is involved, so none of the usual art references fit. The change is how long the existing danger lasts.

The court ink starts at 0.9 seconds and the convoy beam starts at 1.0 seconds. Each step of the chain adds 0.16 seconds, and the chain used here stops at six. The cap is the period minus the warning minus 0.40 seconds, so the warning stays and a clear gap remains.

The taught court bank, 1.8 seconds into the sweep, still lands at chain 0 and misses at chain 6. The convoy pull at 1.5 seconds still lands at chain 0 and misses at chain 4. The marks follow those same windows.

The card appends the clear seconds only on the return step and the gap step, after the chain stake. The v1 slot still writes only Version and CompletedMissions. The chain itself is still session state.
