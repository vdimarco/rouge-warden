# Space, only while the wheels can lock

No new rendering technique is involved, so none of the usual art references fit. This is a phone button and a key the car already reads.

Keyboard Jump and Handbrake are both Space. On foot the phone's Jump button sends it. In a car that same button becomes Brake and sends S, and nothing else holds Space, so the lock, the extra yaw, and the skid never start from a thumb.

Lock is a second button, shown only while driving. Holding it sends Space. Releasing it, or leaving the car, lifts Space. It is not a brake step, so it does not cancel auto gas. S still does. The brake button's driving key stays S, and its on-foot key stays Space.
