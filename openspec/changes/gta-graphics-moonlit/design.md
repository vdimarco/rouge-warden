# Warm light, cool shadow

James Gurney, Color and Light (2010), pairs a warm practical with a cool shadow. The comic node has no shadow ray and no lamp list, so the cool colour is a flat add of (0.05, 0.07, 0.12) on road where the lamp-pool weight is low. A pool that already claimed the pixel keeps its warm colour. NightFactor 0 leaves the colour. The clear-day exposure and the lamp height stay as they are.

Unreal is not installed, so the comic material was not rebuilt. The picture is the same La Fontaine night street as the pool round, with this fill as the only change.
