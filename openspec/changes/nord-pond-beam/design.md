# Four seconds in the steady light

No new rendering technique is involved, so none of the usual art references fit. The beams are the posts the shore already draws. The blink period stays 2.4 seconds, so a four-second hold watches the decoys go dark and come back.

`Apply` still advances a tag of the postcard, so the step machine and the banked index stay put. The campaign calls that tag only after the hold reports done. A blinking beam is not an inside sample. Leaving drops the clock and does not break the chain. The v1 slot still writes only Version and CompletedMissions.
