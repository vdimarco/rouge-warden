# The same three edges, on foot

No new rendering technique is involved, so none of the usual art references fit. The stick uses the edges the wheel already uses: 0.18, 0.45 and 0.75.

The short and middle steps are numpad keys the wheel does not send. Full lock stays W, A, S and D. The arrow keys stay full lock too. A latched sprint still waits for one of those four keys.

The v1 slot still writes only Version and CompletedMissions.
