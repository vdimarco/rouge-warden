# A count and a walk on the card

No new rendering technique is involved, so none of the usual art references fit. The pace is another wrapped line on the mission card.

`QuebecPace` is engine-free. Walking speed is 450 cm/s, the same constant the player uses when not sprinting. Sprint stays 800 cm/s, so the card says "walk" and a sprint arrives sooner. Seconds round to the nearest second, and a short leg still reads as one second.

Linear beats count every step up to the banked index. The ovation counts four player stops, because the followspot and the backdrop share one slot. A rescue counts groups and has no walk. The terrace is five stops; the caller measures the first three from the live objectives, and the park and the release are not walks.

The line does not change CompletedMissions or the v1 save.
