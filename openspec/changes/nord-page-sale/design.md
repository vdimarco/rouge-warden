# Two hundred, or the chain

No new rendering technique is involved, so none of the usual art references fit. The offer is a berry post and a caption, the same parts the gates already use.

The blank page still banks the chain. The sale ends the page and pays 200, which is less than the blank page's base of 780, and it does not call the chain bank. The card keeps marking the blank page. The v1 slot still writes only Version and CompletedMissions.
