# Draw the seventies coupe in the opening shade

The opening shade still draws the constructor box for the player car. The game already replaces that box: `ApplyPaint` loads the seventies coupe (body, cabin, roof, tires, and rims) for body profile 0 and the default teal paint. This round draws that same mesh in the opening camera, at the surveyed car spawn. Pitch, yaw, socket, the pawn, and the grove stay.
