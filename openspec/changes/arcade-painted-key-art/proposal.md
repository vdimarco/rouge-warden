# Painted key art for the arcade machines

Eight games showed a flat frame of the game on their machine and in the SWITCH GAME list: Down the Drain, Olympus, Moonwell, Primordia, Breakthrough, Follow Suit, River Rush and The Lab. Shore of the Ancients, Cottage Brawl and Crimson Rogue show painted key art. Next to those, the eight frames looked unfinished.

## Scope

- Make painted key art for the eight games with Higgsfield. Use each game's old frame as an image reference, so the art keeps the game's colors and subject.
- Show the new art in the SWITCH GAME list for all eight games.
- Show the new art on the machine screens that show a still picture: Moonwell, Primordia (under its live Lenia dish), The Lab, Follow Suit and River Rush.
- Keep the live attract screens of Down the Drain and Breakthrough, and the Olympus machine's own art.
- Keep the old frames in `public/arcade/`. The game scripts that make them (`qa/moonwell/cabinet-art.mjs`, `follow-suit/qa/cabinet-art.mjs`) still write them.

## Player-facing change

The SWITCH GAME list shows painted art on every large tile. The five machines above show the same art on their screens.

## Follow-up: the grid on the arcade page

The user asked for the SWITCH GAME grid on the arcade page, with a more arcade-like look and the same grid.

- An ALL GAMES button in the arcade page's top menu opens the grid. There it is titled ALL GAMES, and its one exit goes back to the machines.
- The grid gets the arcade look on every page: a dark purple room with scanlines, a neon heading, and each game as a small lit CRT screen with its own color glow and a blinking PRESS START on hover or focus. The game being played shows NOW PLAYING.

## Follow-up: Neon Ronin

The user asked for painted art for the Lab toys too. Neon Ronin's art was made on 2026-10-06. The Higgsfield account then ran out of credits, so Loon Echo, Tell Me, Take the Plunge, Up the Creek, Full Tilt and House Rules keep their game frames for now. The user chose to ship Neon Ronin alone.

- Neon Ronin's switcher tile and machine screen show the new art.
