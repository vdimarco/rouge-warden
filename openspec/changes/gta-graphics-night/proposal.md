# Moon and neon on the midnight street

Atmosphere can still move, and a night picture fills the frame. The sky model already drops exposure, turns the lamps on, and lifts window glow. This round paints a moon disc on sky pixels and a spill around windows and headlights that are still bright after that exposure. NightFactor 0 returns the clear-day colour, so the 15:00 frame stays. No reference-game assets.
