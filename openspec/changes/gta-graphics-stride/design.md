# Run in the corner

A new gait does not fit. The clip is the CC0 Quaternius run already in `MenHoodie.glb` and prepared as `A_MenHoodie_Run.fbx`. Sprint is 800 cm/s in `QuebecPace.h`. The sequence plays at that speed divided by 600, so one cycle is 600 cm on the ground.

The corner camera is the one from the street-blade round. It is not moved. The figure is the posed run, rock off, sampled at 0.20 s for the still and at six even times for the cycle, stepping along the view by that 600 cm. There is no blend space. Unreal is not installed, so the sequence is still not an imported uasset. The opening pitch and the socket stay.
