# The chase score row is one printed instrument

Flat play shows the mission, the loonies, the clogs, and the compass as separate flat stickers. The pause menu already prints Ben-Day dots. The play row does not.

## What changes

The row sits on one paper plate with the menu's dot field. Each sticker takes the same print. The coin and the clog icon pick up a face, and the compass arrow sits on a dial. The row's box, the words, and the lock-on gap stay as they are.

## Capabilities

- `swing-ui-polish`: the chase HUD reads as one printed comic instrument.
