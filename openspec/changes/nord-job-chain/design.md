# The same multiple, after the story

No new rendering technique is involved, so none of the usual art references fit. A side job uses the chain rule already written for the story banks.

The multiple is one more than the chain held, and it stops at seven. A spoil pays the job's own reward and clears the chain. A failure only breaks the chain. The story mask is not changed, so a beat that already paid does not pay again. With the chain at zero, the job pays the reward it paid before this change.

The card reads that stake while the side-job guide is up. The v1 slot still writes only Version and CompletedMissions.
