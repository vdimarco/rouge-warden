# Easier NORD driving

The user reports that driving is very difficult and asks for researched improvements. Make the existing default arcade handling more forgiving on keyboard and touch, preserving current floating drag controls, accepted districts/cast, car impacts, traffic, saves and streaming identities.

Scope: gentler acceleration, stronger lift-off slowing, steadier turn-in/fast release, forward tight-corner speed help, and no accidental camera look from driving action buttons. Existing APIs, collision and brake/reverse precedence remain. No new modes, UI settings, analog transport, assets or paid generation.
