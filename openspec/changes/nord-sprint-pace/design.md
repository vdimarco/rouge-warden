# Walk, and the sprint beside it

No new rendering technique is involved, so none of the usual art references fit. The sprint time uses the speed the player already sprints at.

Walk stays 450 centimetres a second. Sprint stays 800. Both round to the nearest second, and a positive distance is at least one second. The card adds the sprint only when that second is shorter, so a one-second walk does not grow a second line that says the same thing.

The v1 slot still writes only Version and CompletedMissions.
