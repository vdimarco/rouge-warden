# Normal precision and rejected preflight

The first pre-export check required maximum angular error below 0.1 degrees. It failed before any FBX was written. A second diagnostic run retained the same gate and measured why: after `Mesh.normals_split_custom_set`, mean error was 0.001576 degrees, p99 0.01343, maximum 0.660888, with 12 out of 310,632 corners above 0.1 degrees. Every provider polygon was already smooth; this was not a flat-face flag error. Both failed attempts and their executed recipes remain in ignored `Saved/Tests/TripoSurface-20261017/rejected-v1` and `rejected-v2`.

Blender custom split normals use geometry-dependent smooth-fan storage. Different original corner directions on some provider-welded vertices collapse to shared stored directions. The receipt retains all twelve outliers, their corresponding provider vertex and both requested/stored normal vectors; repeated provider vertices demonstrate that the data is not twelve arbitrary failed UV matches. The independently proven unique UV triangles and sub-micrometre corresponding surface positions remain unchanged. We have not proved the exact contribution of fan grouping versus finite representation precision for each outlier.

The explicit policy was then set to **mean below 0.02 degrees, p99 below 0.1 degrees and maximum below 1 degree**, recorded in the author and receipt before the actual export. This bounds the small remaining discrepancy while rejecting the raw provider normals by a wide margin. It does not silently relabel the rejected 0.1-degree maximum gate as passed. Fresh import passed those bounds with mean 0.002222, p99 0.016882 and maximum 0.660895 degrees; the same twelve corners remain over 0.1 degrees.

The technique follows Blender's [custom split-normal API](https://docs.blender.org/api/5.0/bpy.types.Mesh.html#bpy.types.Mesh.normals_split_custom_set), [FBX Normals Only export guidance](https://docs.blender.org/api/5.0/bpy.ops.export_scene.html), and [smooth-fan normal storage description](https://docs.blender.org/manual/en/5.2/modeling/meshes/structure.html). A free-vector normal-storage or topology reconstruction pipeline would add complexity and new deformation considerations; neither was needed for this bounded restoration. Native imported normals/tangents and actual shading still require verification.
