## Multiplayer and performance interpretation

Baseline, simulated 100 ms outgoing lag / 2% loss, complete client packet interruption and a separate packaged peer exercise local networking. Native packaged processes additionally cover abrupt process loss, normal timeout and reconnect. These checks do not cover public hosting or router/NAT traversal.

The packaged driving fixture resets the occupied starter to its verified clear start lane before each of two acceleration windows, using native teleport while handbraked. Occupancy, collision and all sixteen traffic cars remain enabled. Host/client position and rotation assertions are retained, with client yaw tolerance accounting for Unreal's native byte quantization. The report records both resets; mapped-route circulation/recovery checks remain in `Population.json`. Separated endpoints do not implement dynamic pedestrian avoidance: residents may pass through mid-route. Discrete SingleNode clips switch without pose crossfades, while root movement remains continuous. Traffic was checked over a minute, not a long soak.

The current final-neighbourhood six-scene [Performance.json](Performance.json) records `passed: false`. At 1280×720, Sherbrooke/Pond/NorthPark p95 values are 17.02/17.26/17.20 ms; at 1920×1080 they are 19.28/19.60/19.48 ms. **All six fail** the requirement below 16.67 ms, although average FPS is 75.6–77.4 at 720p and 65.2–65.9 at 1080p; 0% of sampled frames exceed 33.33 ms. The full median/p95/FPS table is in [README.md](README.md). Static Epic-quality scenes use 100% screen percentage, comic on, uncapped and no VSync, with verified viewport dimensions and 2,398 warmed CSV frames each. Other desktop GPU applications remained active; these measurements describe the shared session and do not isolate the cause of the failures. No isolated GPU benchmark or 60 FPS acceptance is claimed. Static views do not establish worst-case driving, multiplayer or other-hardware performance. Native player/environment inspection's smaller texture/shadow-page budgets are separate from default Epic package settings. Measurement is complete; performance acceptance remains open.

`PackagedSoak.json` retains an earlier 30-minute / 60-cycle lifecycle test. It predates this animation/population update and was not repeated. RSS is diagnostic, not proof of leak-free memory use. Earlier HUD/sound-word captures and contended performance reports are historical evidence, not measurements of this revision.
