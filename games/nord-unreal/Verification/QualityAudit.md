- A sparse district now includes bounded traffic and walkers. Tests exposed later jams beyond the initial movement check; static route filtering and junction reservations address those cases.

Previously corrected blocked-exit captions, interaction/HUD priority and stale remote throttle remain covered by the regression suite. Remote controls clear after 0.5 seconds without a valid update; normal degraded packets and complete interruption are tested separately.

## Multiplayer and performance interpretation

Baseline, simulated 100 ms outgoing lag / 2% loss, complete client packet interruption and a separate packaged peer exercise local networking. Native packaged processes additionally cover abrupt process loss, normal timeout and reconnect. These checks do not cover public hosting or router/NAT traversal.

The packaged driving fixture resets the occupied starter to its verified clear start lane before each of two acceleration windows, using native teleport while handbraked. Occupancy, collision and all sixteen traffic cars remain enabled. Host/client position and rotation assertions are retained, with client yaw tolerance accounting for Unreal's native byte quantization. The report records both resets; the longer mapped-route circulation/recovery checks remain in `Population.json`.

The last recorded post-atlas, pre-expression six-scene package performance run records `passed: false`; it does not measure the regenerated crew. Only 1280×720 Sherbrooke meets the required p95 below 16.67 ms, at 14.56 ms. The 720p Pond/NorthPark values are 23.12/28.98 ms; all three 1920×1080 views fail at 28.47/29.59/29.03 ms. The full median/p95/FPS table is in [README.md](README.md). The benchmark uses static Epic-quality views at 100% screen percentage, uncapped and without VSync, with verified viewport dimensions and 2,398 warmed frame samples per scene. Other desktop GPU applications remained active; these measurements describe the shared session and do not isolate the cause of the failures. No isolated GPU benchmark or 60 FPS acceptance is claimed. Static views do not establish worst-case driving, multiplayer or other-hardware performance. Editor inspection's smaller texture/shadow-page budget is separate from the default Epic package settings. Performance acceptance remains open.

`PackagedSoak.json` retains an earlier 30-minute / 60-cycle lifecycle test. It predates this animation/population update and was not repeated. RSS is diagnostic, not proof of leak-free memory use. Earlier HUD/sound-word captures and contended performance reports are historical evidence, not measurements of this revision.
