# Unified Plateau map — current checkpoint

The active `/Game/Maps/LaFontaine` map uses the baked Plateau environment from the separate GTA-NORD project at `eddc54c`, with Warden's 14 authored `QuebecParkResident` routes and eight driveable parked `QuebecCar` actors restored. The saved map has 2,701 actors (2,679 baked environment actors plus 22 restored gameplay actors). Warden's campaign, crew, vehicle handling and native road graph remain the gameplay source. The separate GTA-NORD checkout was read only during this import.

The merge started from an ignored local recovery baseline covering the original Warden map, differing shared assets and existing native saves. The reviewable [hash and save inventory](UnifiedPlateauBaseline.json) confirms that 4,938 protected source files, 16 Warden recovery copies, 4,652 imported asset/input files and the original isolated save retain their recorded bytes. The [merge report](UnifiedMapMerge.json) records the restored actor count and routes. `Data/Plateau/BaseGeometry` contains the baked source project's road, marking and path OBJ inputs; Warden's `Data/LaFontaine/layout.json` and generated native road graph were retained. `Scripts/upgrade_plateau.py` is a guarded refresh for this **already integrated baked map**, not the import method. Its CPU preflight test passes, but full regeneration and fresh-load verification after it have not been run.

Visual tree contact, driving feel, exact Montréal building likeness, facial expression quality and Google Street View parity are not established by these tests. The buildings' heights and façades include estimates; terrain is mostly flat. No Google imagery is included.
