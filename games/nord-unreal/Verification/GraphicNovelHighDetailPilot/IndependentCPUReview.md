Native deformed-pose review is required before replacing the earlier pilot.

This is a stochastic candidate comparison: seed control is unavailable. Prior output is 768 px wide and new output 1024 px wide, both 16 samples; new images were downsampled to prior dimensions for pairing. GLB rest-material and FBX own-clip shader methods differ within each studio pass, so do not attribute all appearance differences to polygon count or geometry.
