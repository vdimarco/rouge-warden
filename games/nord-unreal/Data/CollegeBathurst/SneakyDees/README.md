# Original Sneaky Dee's corner dressing

`Scripts/prepare_sneaky_dees.py` builds a thin, deterministic visual layer on the retained OSM footprint, including College frontage, its short corner chamfer and Bathurst frontage. It reuses `plateau_mesh.Mesh` boxes and the existing Plateau material palette. `facade.json` records every source/input hash, OBJ hash, material, triangle count, source edge, sign and clearance. Ignored `Geometry/` is reproducible with the existing geographic Python environment.

The two-storey exterior is informed by the [official venue](https://www.sneakydees.com/) and the [City's existing-site report, pages 2–3](https://www.toronto.ca/legdocs/mmis/2026/te/bgrd/backgroundfile-286881.pdf). Stone ground cladding, white upper cladding, brick divisions, dark frames, coloured upper panels and continuous fascia are illustrative. The sign lettering is original vector geometry spelling “SNEAKY DEE'S”; no venue photograph, logo, mural, comic excerpt or third-party font is copied. Reference-photo date/authorship are unspecified. See the parent README for current streetscape and withdrawal/heritage-study sources.

The OSM footprint and shared-block 7.52 m lidar height are retained. Two storeys are sourced; bay spacing, doors, floor heights, colour arrangement, courses, sign proportions and parapets are estimates. Door panels do not grant interior access. Native landmark collision is preserved. All added components use `NoCollision`, project at most 25 cm from the footprint, and are checked against the sidewalk centreline, spawn, full starter-car rectangle and streetcar centreline. The current strip widths and ground elevation remain estimates.

Opaque skins sit beyond the original 3 cm generic window cards on these three faces only. Original `SM_Glass` and `SM_Landmark` packages and all unowned static-mesh actor states remain unchanged; no broad glass hiding or collision replacement is allowed. Streetcar platforms, cycle tracks and first-block street furniture require a separate reviewed layer. Native rendering must accept this corner before extending the treatment.

Run preparation/tests with `/home/von/.cache/nord-geo-venv/bin/python Scripts/prepare_sneaky_dees.py` and `Scripts/test_sneaky_dees.py`. Apply only in a fresh `-NullRHI` editor with `/Game/Maps/CollegeBathurst` already loaded. `Scripts/apply_sneaky_dees.py` preflights inputs/materials/classes/map/collider and refuses existing owned actors/assets before importing to `/Game/CollegeBathurst/SneakyDees`. Supply `-NordSneakyDeesReport=/absolute/path/under/project/Saved/Tests/.../apply.json` for a chosen evidence destination; otherwise a fresh timestamped report is written there. The apply report is not visual acceptance.

After a separate editor launch, `apply_sneaky_dees.verify(unreal, apply_report_path, report_path=...)` reads all eight saved groups, triangle counts, bounds, exact materials, transforms, visibility, `NoCollision` and disabled shadow casting. It compares all original static-mesh actor states and the landmark/glass package hashes with the apply baseline, and reads saved mesh-description sign triangles to require College/Bathurst outward normals. The normal calculation follows the installed engine's `StaticMeshOperations.cpp` left-handed cross-product convention and the existing `verify_plateau_wayfinding.py` mesh-description API pattern. This check does not import/save native assets or accept appearance.
