`osm.xml` is the unmodified source. `layout.json`, `Geometry/*.obj`, and `Source/Quebec/LaFontaineMap.h` are generated by `python3 Scripts/prepare_lafontaine.py`. Imported geographic meshes are in `Content/LaFontaine`. No Google imagery or extracted Google geometry is used.

Local origin: latitude 45.525, longitude -73.5699. Unreal X is east, Y is north, centimetres. Equirectangular projection is appropriate for this approximately 1 km district; this is not survey-grade terrain. OBJ import flips its Y axis, so the export negates Y and reverses winding. Flat ground; no elevation survey. Streets and paths use estimated widths. Unspecified building heights use three storeys. Windows, materials, roof appearance, and tree crowns are procedural approximations. Mapped tree positions, building footprints, park boundary, ponds, and paths retain source geography. Only ways wholly inside the playable bounds are included; roads terminate at the district edge. Pond water is a shallow visual surface over the shared ground, without swimming simulation.

The address node for 1334 Rue Sherbrooke Est is OSM node 11972684994. Spawn is the nearest mapped pedestrian path and the car is on nearby Rue Sherbrooke Est. This is an exterior neighborhood, not a reconstructed private interior. Missions are public park exploration objectives, not inferred personal ambitions.

Regeneration: close this project's editor, preserve the existing LaFontaine map, run the preparation script, then run `Scripts/create_lafontaine.py` with UnrealEditor-Cmd -ExecutePythonScript. The Unreal generator refuses to overwrite the map. Rebuild C++ after preparing because the HUD and recovery points use the generated header.
